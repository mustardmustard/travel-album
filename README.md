# IN MAX — 健身房影像展

一个单文件的健身房照片展示网站：照片沿着上下两条带流动，中间是会躲开鼠标的点阵大字，点进去是横向滑动的项目章节页。

> 当前 `photos/` 为 28 张 AI 生成的健身房演示照片，按 **硬拉 / 臀腿 / 肩部 / 瑜伽 / 减脂 / 舞蹈 / 普拉提** 分为七章（每章 1 张场馆氛围 + 3 个动作），前四章按一次训练由重到轻，后三章是三种项目性格。不同章的照片分别放在 `photos/sq/<章节>/`、`photos/full/<章节>/` 子文件夹里。首页点阵大字是 `MAX 健身工作室`，左上角为 `TRAINING IN MAX`，副标题 `TRAINING 2026`，项目行列出七个项目，署名 `XCJ`。标题为 `IN MAX — 健身房影像展`；强调色沿用站点品牌色蒂芙尼蓝 `#0ABAB5`（演示素材为 AI 生成，若要严格按「颜色来自照片」重取，可跑 `analyze_photos.py`）；黑色文字砖为 `Training Log / IN MAX`。顶部导航在 `ALBUM` 左侧新增了 `CONTACT US`，点进 `#/contact` 显示 `MAX 工作健身室`、微信 `MAX20240108`、联系人 `MAX-陈`、电话 `18820216492`（可一键复制）；首页 hero-top 右侧原来的 `CONTACT US` 已移除。演示照片可用真实训练照片按同名替换，原始图与上一版旅行照片分别见 `备份文件/健身照片原始/` 与 `备份文件/photos-旅行相册-改版前/`。

## 互动

首页是上下两层：**上层**是 Tiffany 式的编排（顶部细信息行、居中的点阵大字标题、一行章节细导航），下面是**手风琴式类目卡**——默认第一张展开，鼠标移到哪张哪张就用约 1.05s 的缓出曲线慢慢展开成圆角大图看到照片全貌，其余六张自动收成带编号的细长竖条，点进去是对应章节；七张卡全部参与手风琴，窄屏下把 `--slim` 收到 26px 给展开卡留出可读宽度；展开的那张会有一层缓慢扫过的蒂芙尼蓝渐变微光和很淡的外发光。过渡用可插值的 `flex-basis:0%`（`px ↔ auto` 不可插值会跳一下），再配合 hover-intent（鼠标停下 90ms 才提交目标，忽略动画期间浏览器补发的同坐标事件），所以放慢之后既丝滑也不会被滑过来的卡片带跑。**下层**是原来的照片环，按需求去掉了左右两条竖向照片带，只留上下两条横向照片带；上栏照片带下方、下栏照片带上方各有一层贴住水线、向倒影末端渐隐的水面倒影（以页面水平中线近似对称）。倒影是一份独立的镜像 DOM（不再用 `-webkit-box-reflect`，这样 Chrome / Edge / Safari / Firefox 都能看到），和照片环同步轮动。倒影盒分成三层：内层 `.reflect-img` 放照片镜像，渐隐遮罩与 `brightness(.52)` 压暗只作用在这一层；外层 `.reflect` 只铺一层贴纸色的白色水面底色（贴着水线最实、向倒影末端渐隐；圆角接缝与倒影尾部露出的都是白纸，不再是深色缺口）；最上面是独立的 `<canvas class="water-canvas">` 涟漪层，不吃照片镜像的遮罩与压暗，只跟着同一个倾角一起斜。水面本身静止，canvas 平时完全透明；遮罩放在内层而不是外层，是为了让**鼠标涟漪能覆盖整片倒影**：遮罩若放在外层会把照片和涟漪一起抹掉。

水纹历经几轮尝试后按需求收敛成**静水**：删掉了等距横条纹、同心圆环、1px 水面亮线，也删掉了多方向行波高度场、波峰脊线、交叉波以及 SVG `feTurbulence` + `feDisplacementMap` 的噪声位移——这些自发图案要么机械，要么会把照片带底边采样成一条白线。现在**只有鼠标划过倒影**才在命中处画几圈横向拉长（1.7:1）的小椭圆涟漪：亮环在前、暗环紧随，中心一点极淡的隆起高光，约 1 秒消散；最多同时 4 圈，按 110ms / 24px 节流。canvas 只有 1/3 分辨率，浏览器放大自带柔化；涟漪散尽后立刻清空画布，静止时零绘制开销。滚轮仍会让整片倒影按速度倾斜（方向跟着滚动方向，停下约 1 秒弹簧回正），但不会再让水面自己起波纹。倒影前面还挂着一层**透明帘子**（`.refl-curtain`）：一串不规则节奏的柔光/柔影竖条纹以 240px 为周期横向漂移（16s 一圈，GPU transform、无缝循环），外层固定在水线一端、以 ±2.4° 缓摆（14s 一个来回），像风吹动一层薄纱；上栏倒影的帘子往反方向漂。整层用遮罩贴着水线最实、到倒影末端渐隐，滚轮带来的整体倾角同样带动它；纯 CSS 动画不进主循环，60fps 不受影响，鼠标涟漪照常画在帘子之上。上下两栏倒影共用同一个 `--refl-h` 高度和同一条渐隐曲线，因此**完全等高**；这个高度会先从一屏高度里扣出来再算照片环（`layoutRing()` 里的 `budget`），所以「上栏照片＋倒影＋中间文字＋下栏照片＋倒影」滚到照片环时刚好一屏看全，页面也不会再被倒影撑出多余的滚动空间（上栏倒影的镜像格用 `top:calc(var(--refl-h) - var(--c) - 2px)` 上移（照片底边贴水线），下栏倒影的镜像格放回首格（照片顶边贴水线））。上层用滚轮 / 触摸正常翻页，滚到照片环区域后滚轮继续推动照片环，点左上角 logo 可以回到顶部。点阵大字虽移到了上层，躲鼠标、悬停照片重组成章节名并染上照片颜色的交互都还在。开启系统的「减弱动效」时，光晕、倾斜与鼠标涟漪都会关掉，倒影就是一面静止的白镜面。

- **照片环**：滚轮、触摸拖动或方向键推动照片环，松手后带惯性停下。照片格只在靠外的一侧保留圆角（26px / 窄屏 20px，与上层手风琴卡片一致），贴水线的一侧是直角；条带左右两端的角由条带容器补成圆角，倒影格为直角；没人操作时会自己慢慢转，鼠标停在照片上时暂停。手机上先轻点照片预览中央粒子的章节文字和照片颜色，再点同一张或中间的「进入章节」才跳转；滑动仍用于推动照片环。桌面横屏时中间文字区横向缩到原来的 80%、纵向再收到 70%（`layoutRing()` 里的 `SCALE_X` / `SCALE_Y` 可调），两行照片和文字因此更紧凑，上下两条带仍无缝铺满；竖屏沿用原尺寸以免文字压到照片上。
- **点阵字**：鼠标靠近时点会散开、再弹回原位。悬停任意照片，点阵会重组成那一章的名字，并染上那张照片的颜色。
- **章节页**：横向惯性滚动，照片保持原始比例，带视差。底部的风格切换台可以把整章照片实时印成 `原图 / 油墨 / 网点 / 色块` 四种样子（键盘 1–4），色块模式会给出每张照片的 5 个主色。
- **单张大图**：在章节页点任意照片打开。点阵从缩略图里飞出来，由粗到细显影成照片；章节当前是油墨、网点或色块风格时，大图也显影成那个风格。鼠标变成放大镜（滚轮调倍数，放到足够大会直接显示原图像素），放大镜里永远是原片，旁边显示指针下的色号和这张照片的 5 个主色（点击复制）。← → 换张，1–4 换风格，Esc、Close 或点空白处关闭；手机上按住照片拖动看细节。网址会变成 `#/ch/章/张/view`，可以直接分享到某一张，浏览器返回键可以关掉大图。风格作品的署名显示在大图侧栏里。
- **声音**：进站默认开启；若浏览器限制自动播放，第一次触摸或按键时自动接通（滚轮不算），点顶部的 Sound 可以关掉，关闭后不会因后续触摸自动重新开启。整册换成**欧美动感 house / EDM**，依旧全部由振荡器和噪声现场合成、零音频文件：底鼓是 150→48Hz 的正弦下扫加一记极短噪声点击，拍手由三连带通噪声叠成，hi-hat 走 7.2kHz 高通（closed 45ms / open 180ms），`V.sub` 是纯低频长音，`V.bass` 是锯齿加低通包络的切分律动，`V.stab` 用两根微微走音的锯齿叠成和弦，`V.lead` 带一点起音滑音，另有 `V.sweep`（上扫）、`V.impact`（落地冲击）与 `V.air`（气息）。混响从钢琴时代的 4.2s 长尾缩到 **1.2s**、wet 从 .52 降到 .2，让四四拍鼓点干净不糊。音阶换成多利亚 `[0,2,3,5,7,9,10]`，基准音 `base:57`。七章排成 **124 / 126 / 128 / 100 / 132 / 130 / 92 BPM**：硬拉是四四拍重底鼓＋反拍开镲＋每小节 sub，臀腿是 16 分 hi-hat＋切分贝斯，肩部在 2/4 拍加拍手并用 lead 走短句，瑜伽降到 100 BPM、soft kick 每两拍一次；减脂冲到 132 BPM 的双 kick＋16 分 hi-hat＋每四小节一次 riser，舞蹈是 130 BPM 的 house 反拍开镲与 2/4 拍拍手，普拉提回到 92 BPM 的长 pad＋气息留白。`LB_SND` / `VOICE` / `SCENES` 三个数组各 7 项，与 `CHAPTERS` 一一对应。每章环境声的 `tick` 一次排满一个小节（4 拍）再返回下一小节起点，节拍不受 60ms 调度抖动影响。首页划过照片弹一个音，滚动照片环连成一段旋律。大图里每章有自己的一套声音（聚拢、显影、成像、切换、关闭各不相同），放大镜划过照片时会把指针下的亮度变成音高。

- **作者页**：顶部 About、首页署名和章节页署名都进入 `#/about`，沿用强调色幕布转场，展示作者和可直接跳转的社交图标。个人信息在 `THEME.author` 中配置。
- **联系页**：顶部导航最左侧的 `CONTACT US`（在 `ALBUM` 左边）进入 `#/contact`，沿用同一套幕布转场；显示场馆名、微信、联系人、电话，每项带一键复制，电话可直接拨号，Back 会回到进入前的页面。信息集中在 `index.html` 风格区顶部的 `CONTACT` 常量里，换场馆只改这一处。窄屏放不下五个入口时按断点先隐藏 `Chapters`，`CONTACT US` 始终保留。

## 本地运行

需要用本地服务器打开（直接双击 `index.html` 时，浏览器不允许读取照片像素：首页点阵字仍会用 `photos/tints.js` 里预先算好的色块染色，但风格切换和大图显影会失效）：

```bash
python3 -m http.server 8765
```

然后访问 http://localhost:8765 。字体来自 Google Fonts，首次打开需要联网。

> **必须在仓库根目录 `D:\travel-album-main` 下执行**，不要在 `photos/sq/` 或 `photos/full/` 里启动：那样服务器根目录只有 jpg、没有 `index.html`，浏览器会显示成「Directory listing for /」的文件列表，看起来像网页坏了。端口换成 8000 也没问题，关键是启动目录要对。本项目当前 8000 与 8765 两个端口都已指向仓库根目录，打开任意一个都能看到相册。另外不要直接双击 `index.html`（`file://` 下读不到照片像素）。

## 换照片

照片在 `photos/sq/<章节>/`（640×640 方图，用在照片环和首页卡上）和 `photos/full/<章节>/`（长边 1600，用在章节页和大图上），**不同章节分别放在不同子文件夹**，两边目录与文件名一致。当前 7 个目录：`deadlift / glutes / shoulders / yoga / cutting / dance / pilates`。章节、照片和图注在 `index.html` 顶部的 `CHAPTERS` 里；标题、首页大字、字体、音阶、动效参数和联系信息在旁边的 `THEME`、`CONTACT` 里。原始照片按项目分文件夹、文件名用英文动作名，再跑：

```bash
python3 skills/photo-album/scripts/prepare_photos.py <原始照片文件夹> \
    --label-from-folder --sq-fit \
    --order deadlift,glutes,shoulders,yoga,cutting,dance,pilates --out .
```

它会按章节生成 `photos/sq/<章节>/`、`photos/full/<章节>/`、`photos/tints.js` 和根目录的 `chapters.json`（每章 `dir` + `label`，照片 `src / w / h / from`），把打印出的 `src`、`w`、`h` 抄进 `CHAPTERS` 即可。`--order` 只决定 `chapters.json` 的章节顺序；`CHAPTERS` 里的展示顺序另定。`--sq-fit` 让竖幅全身动作等比缩进 640×640 的浅色底，不被居中裁切切掉手脚。手动替换了 `photos/sq/<章节>/` 里的图，要再跑一次 `python3 skills/photo-album/scripts/bake_tints.py`（它递归扫描所有章节子文件夹）。

**`CHAPTERS` 里的 `src` 必须带章节目录**，例如 `cutting/cutting-01-cardio`；`photoURL(dir, src)` 会拼成 `photos/sq/cutting/cutting-01-cardio.jpg`。`tints.js` 的键名也是这个相对路径，两边必须完全一致，否则 `file://` 下悬停照片会全部退回强调色。照片允许 jpg / png 混用：非 jpg 的条目在 `CHAPTERS` 里加 `ext:".png"`；`w`、`h` 要填 full 图的实际宽高。加章时别忘了把 `LB_SND` / `VOICE` / `SCENES` 也补成相同项数。

## 用你自己的照片做一个

仓库里带了一个 skill：[`skills/photo-album/`](skills/photo-album/SKILL.md)，这一版已经改造成**健身房照片展示**专用。把它和按项目分好文件夹的照片一起交给任何一个 agent（Claude Code、Codex、Cursor 等），它会按下面的步骤做出一个结构相同、风格属于你这家场馆的网站：

1. 量照片：主色、明暗、冷暖、竖幅比例，并生成一张带项目标签的缩略图总览 `contact.jpg`；
2. 按训练项目分章（`style-dna.yaml` 里的 `exercise / body_part / intensity`），并读出风格 DNA：纸色、强调色、字体、动效性格、粒子形态、风格台效果、音阶、每章的节拍与乐器；
3. 用几个问题跟你确认（会员肖像授权也在这一步确认）；
4. 把 DNA 填进模板，并用 `prepare_photos.py --label-from-folder` 生成的照片标签搭出 `CHAPTERS`（本站 7 章 28 张，照片按章节分子文件夹）。

`index.html` 顶部标了「风格区」的地方是可变的，其余是引擎。skill 的原理和规则写在 `skills/photo-album/references/` 里。
