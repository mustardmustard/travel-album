# Travel Album

一个单文件的互动相册网站：照片沿着方框边缘逆时针流动，中间是会躲开鼠标的点阵大字，点进去是横向滑动的章节页。

> 当前 `photos/` 为 25 张生活照片，按景德镇 / 湖南 / 武林 / 河南 / 三亚 / 江西分为六章；首页点阵大字为 `XCJ`，左上角为 `TRAVEL THE WORLD`，副标题 `TRAVEL 2025/2026`，地点行 `Jingdezhen·Hunan·Wulin·Henan·Sanya·Jiangxi`，署名 `XCJ`，六章声音按题材重编。标题为 `The World — XCJ 的旅行相册`；强调色已由模板最初的国际橙 `#F0481A` 改为蒂芙尼蓝 `#0ABAB5`；黑色文字砖为 `Travel Log / The World`（该砖带 `.x` 类，按全站 `--case:uppercase` 显示为大写）。各批原始照片见 `备份文件/`。

## 互动

首页是上下两层：**上层**是 Tiffany 式的编排（顶部细信息行、居中的点阵大字标题、一行章节细导航），下面是**手风琴式类目卡**——默认第一张展开，鼠标移到哪张哪张就用约 1.05s 的缓出曲线慢慢展开成圆角大图看到照片全貌，其余三张自动收成带编号的细长竖条，点进去是对应章节；展开的那张会有一层缓慢扫过的蒂芙尼蓝渐变微光和很淡的外发光。过渡用可插值的 `flex-basis:0%`（`px ↔ auto` 不可插值会跳一下），再配合 hover-intent（鼠标停下 90ms 才提交目标，忽略动画期间浏览器补发的同坐标事件），所以放慢之后既丝滑也不会被滑过来的卡片带跑。**下层**是原来的照片环，按需求去掉了左右两条竖向照片带，只留上下两条横向照片带；每条带下方各有一层紧贴底边、向下渐隐的水面倒影。倒影是一份独立的镜像 DOM（不再用 `-webkit-box-reflect`，这样 Chrome / Edge / Safari / Firefox 都能看到），和照片环同步轮动；用 `brightness(.52)` 加一层深灰水面底色把倒影压暗，渐隐铺满整层。水波痕迹刻意做得淡：`::before` 是低对比的同心椭圆涟漪环，`::after` 是极淡的明暗横纹加一道 1px 水面亮线。真正的起伏来自 SVG `feTurbulence` + `feDisplacementMap`（`<filter id="waterRippleFilter">`），它把镜像照片**本身**扭出连续水纹。所有水波共用一个相位 `REFL.phase`，**推进速度随照片滑动速度变化**——速度取滚轮冲量与照片环惯性的较大者（方向键、触摸拖动同样生效）：静止约 10 秒一个周期，慢滚约 3 秒，快滚约 0.8 秒（约 13 倍）；位移幅度同步从约 10px 涨到约 20px，倾斜方向跟着滚动方向，停下后约 1 秒回正。相位逐帧累加，CSS 变量每 2 帧、SVG 滤镜每 6 帧写入以保持流畅。SVG 滤镜是渐进增强：老浏览器不支持时，CSS 水线与涟漪仍可见。照片环下方因此多留出约半格高的水面，用来完整显示倒影。上层用滚轮 / 触摸正常翻页，滚到照片环区域后滚轮继续推动照片环，点左上角 logo 可以回到顶部。点阵大字虽移到了上层，躲鼠标、悬停照片重组成章节名并染上照片颜色的交互都还在。开启系统的「减弱动效」时，光晕、倾斜与水波会自动关掉。

- **照片环**：滚轮、触摸拖动或方向键推动照片环，松手后带惯性停下；没人操作时会自己慢慢转，鼠标停在照片上时暂停。手机上先轻点照片预览中央粒子的章节文字和照片颜色，再点同一张或中间的「进入章节」才跳转；滑动仍用于推动照片环。桌面横屏时中间文字区缩到原来的 80%、照片格相应放大约 20%（`layoutRing()` 里的 `CENTER_SCALE` 可调），上下两条带仍无缝铺满；竖屏中间区本来就窄，保持原尺寸以免文字压到照片上。
- **点阵字**：鼠标靠近时点会散开、再弹回原位。悬停任意照片，点阵会重组成那一章的名字，并染上那张照片的颜色。
- **章节页**：横向惯性滚动，照片保持原始比例，带视差。底部的风格切换台可以把整章照片实时印成 `原图 / 油墨 / 网点 / 色块` 四种样子（键盘 1–4），色块模式会给出每张照片的 5 个主色。
- **单张大图**：在章节页点任意照片打开。点阵从缩略图里飞出来，由粗到细显影成照片；章节当前是油墨、网点或色块风格时，大图也显影成那个风格。鼠标变成放大镜（滚轮调倍数，放到足够大会直接显示原图像素），放大镜里永远是原片，旁边显示指针下的色号和这张照片的 5 个主色（点击复制）。← → 换张，1–4 换风格，Esc、Close 或点空白处关闭；手机上按住照片拖动看细节。网址会变成 `#/ch/章/张/view`，可以直接分享到某一张，浏览器返回键可以关掉大图。风格作品的署名显示在大图侧栏里。
- **声音**：进站默认开启；若浏览器限制自动播放，第一次触摸或按键时自动接通（滚轮不算），点顶部的 Sound 可以关掉，关闭后不会因后续触摸自动重新开启。每一章有一种由浏览器现场合成的环境声；全站用羽调式五声音阶（宫商角徵羽落在羽音，中国风的底色），首页划过照片会弹出一个音，滚动照片环就是一段古筝的旋律。六章分别是景德镇的木鱼与编钟、湖南的鼓点与轮指琵琶、武林的山风与箫、河南的扬琴与编钟、三亚的笛与扬琴、江西的二胡与古筝。大图里每章有自己的一套声音（聚拢、显影、成像、切换、关闭各不相同），放大镜划过照片时，会把指针下的亮度变成音高。乐器全部由振荡器和噪声现场合成——古筝、琵琶、笛、箫、二胡、编钟、鼓、锣、木鱼、扬琴，没有使用任何音乐文件。

- **作者页**：顶部 About、首页署名和章节页署名都进入 `#/about`，沿用相册的蒂芙尼蓝幕布转场，展示作者和可直接跳转的社交图标。个人信息在 `THEME.author` 中配置。

## 本地运行

需要用本地服务器打开（直接双击 `index.html` 时，浏览器不允许读取照片像素：首页点阵字仍会用 `photos/tints.js` 里预先算好的色块染色，但风格切换和大图显影会失效）：

```bash
python3 -m http.server 8765
```

然后访问 http://localhost:8765 。字体来自 Google Fonts，首次打开需要联网。

> **必须在仓库根目录 `D:\travel-album-main` 下执行**，不要在 `photos/sq/` 或 `photos/full/` 里启动：那样服务器根目录只有 jpg、没有 `index.html`，浏览器会显示成「Directory listing for /」的文件列表，看起来像网页坏了。端口换成 8000 也没问题，关键是启动目录要对。本项目当前 8000 与 8765 两个端口都已指向仓库根目录，打开任意一个都能看到相册。另外不要直接双击 `index.html`（`file://` 下读不到照片像素）。

## 换照片

照片在 `photos/sq/`（640×640 方图，用在照片环上）和 `photos/full/`（长边 1600，用在章节页上），两边文件名一致。章节、照片和图注都在 `index.html` 顶部的 `CHAPTERS` 数据里；标题、首页大字、字体、音阶和动效参数在旁边的 `THEME` 里。整理好的照片可以用 `skills/photo-album/scripts/prepare_photos.py` 生成，它会顺带更新 `photos/tints.js`；手动替换了 `photos/sq/` 里的图，要再跑一次 `python3 skills/photo-album/scripts/bake_tints.py`。

照片允许 jpg / png 混用：非 jpg 的条目在 `CHAPTERS` 里加 `ext:".png"`，路径统一由 `photoURL(dir, src)` 拼接，键名（不含扩展名）同时对应 `tints.js` 的色块。`bake_tints.py` 会扫 jpg / png / webp；`w`、`h` 要填 full 图的实际宽高。

## 用你自己的照片做一个

仓库里带了一个 skill：[`skills/photo-album/`](skills/photo-album/SKILL.md)。把它和你的照片文件夹一起交给任何一个 agent（Claude Code、Codex、Cursor 等），它会按下面的步骤做出一个结构相同、风格属于你自己照片的网站：

1. 量照片：主色、明暗、冷暖、夜景比例，并生成一张缩略图总览；
2. 从这些数据里读出一份"风格 DNA"：纸色、强调色、字体、动效性格、粒子形态、风格台效果、音阶、每章的声音；
3. 用几个问题跟你确认；
4. 把 DNA 填进模板。

`index.html` 顶部标了「风格区」的地方是可变的，其余是引擎。skill 的原理和规则写在 `skills/photo-album/references/` 里。
