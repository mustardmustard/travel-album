# Travel Album

一个单文件的互动相册网站：照片沿着方框边缘逆时针流动，中间是会躲开鼠标的点阵大字，点进去是横向滑动的章节页。

> 当前 `photos/` 为 25 张生活照片，按景德镇 / 湖南 / 武林 / 河南 / 三亚 / 江西分为六章；首页点阵大字为 `XCJ`，左上角为 `TRAVEL THE WORLD`，副标题 `TRAVEL 2025/2026`，地点行 `Jingdezhen·Hunan·Wulin·Henan·Sanya·Jiangxi`，署名 `XCJ`，六章口琴吹法按题材重编。标题为 `The World — XCJ 的旅行相册`；强调色已由模板最初的国际橙 `#F0481A` 改为蒂芙尼蓝 `#0ABAB5`；黑色文字砖为 `Travel Log / The World`（该砖带 `.x` 类，按全站 `--case:uppercase` 显示为大写）。各批原始照片见 `备份文件/`。

## 互动

首页是上下两层：**上层**是 Tiffany 式的编排（顶部细信息行、居中的点阵大字标题、一行章节细导航），下面是**手风琴式类目卡**——默认第一张展开，鼠标移到哪张哪张就用约 1.05s 的缓出曲线慢慢展开成圆角大图看到照片全貌，其余三张自动收成带编号的细长竖条，点进去是对应章节；展开的那张会有一层缓慢扫过的蒂芙尼蓝渐变微光和很淡的外发光。过渡用可插值的 `flex-basis:0%`（`px ↔ auto` 不可插值会跳一下），再配合 hover-intent（鼠标停下 90ms 才提交目标，忽略动画期间浏览器补发的同坐标事件），所以放慢之后既丝滑也不会被滑过来的卡片带跑。**下层**是原来的照片环，按需求去掉了左右两条竖向照片带，只留上下两条横向照片带；每条带下方各有一层紧贴底边、向下渐隐的水面倒影。倒影是一份独立的镜像 DOM（不再用 `-webkit-box-reflect`，这样 Chrome / Edge / Safari / Firefox 都能看到），和照片环同步轮动。倒影盒分成三层：内层 `.reflect-img` 放照片镜像，渐隐遮罩、`brightness(.52)` 压暗和 SVG 位移滤镜都只作用在这一层；外层 `.reflect` 只铺一层深灰水面底色（兼作深色垫底，位移把边缘拉开时露出的是深色而不是白纸，照片带底边就不会再出现白亮线）；最上面是独立的 `<canvas class="water-canvas">` 水面层，不吃位移滤镜，只跟着同一个倾角一起斜。渐隐遮罩放在内层而不是外层，是为了让**水波纹覆盖整片倒影**：遮罩若放在外层会把照片和波纹一起抹掉。

水纹不再用等距横条纹、同心圆环或 1px 水面亮线这些机械图案（那条亮线正是照片带底边白线的来源）。`WATER.waves` 是五组波长 / 方向 / 速度都不同的行波，逐像素叠加成高度场，再用「沿水深方向排列 + 被高度场推弯」的波峰相位画出细脊线，另加一组约 24° 的弱交叉波和沿线明暗包络，于是波纹弯曲、交错、时隐时现且方向不一，接近真实水面；迎光坡亮、背光坡暗提供柔和体积感。相位可分离成行/列因子，逐像素不用再算三角函数；画布只有 1/3 分辨率，浏览器放大后自带柔化。**鼠标划过倒影**会在命中处注入一圈扩散衰减的阻尼波，同时加进高度场把周围波峰线掰弯；水面是斜着看的，所以涟漪按 1.7:1 压成横向拉长的小椭圆，最多 4 圈、约 1.1 秒消散。镜像照片本身的起伏来自 SVG `feTurbulence` + `feDisplacementMap`（`<filter id="waterRippleFilter">`），噪声的 x/y 频率各自缓慢摆动，扭曲方向会不断变化，幅度刻意收小以免把照片撕成竖向条子。所有水波共用一个相位 `REFL.phase`，**推进速度随照片滑动速度变化**——速度取滚轮冲量与照片环惯性的较大者（方向键、触摸拖动同样生效）：静止约 10 秒一个周期，慢滚约 3 秒，快滚约 0.8 秒（约 13 倍）；位移幅度同步从约 4px 涨到约 10px，倾斜方向跟着滚动方向，停下后约 1 秒回正。相位逐帧累加，CSS 变量每 2 帧、SVG 滤镜每 6 帧写入，水面画布每 2 帧重绘一次以保持流畅。SVG 滤镜是渐进增强：老浏览器不支持时，canvas 水纹与鼠标涟漪仍照常可见。上下两栏倒影共用同一个 `--refl-h` 高度和同一条渐隐曲线，因此**完全等高**；这个高度会先从一屏高度里扣出来再算照片环（`layoutRing()` 里的 `budget`），所以「上栏照片＋倒影＋中间文字＋下栏照片＋倒影」滚到照片环时刚好一屏看全，页面也不会再被倒影撑出多余的滚动空间（镜像格用 `top:calc(var(--refl-h) - var(--c) - 2px)` 上移，保证紧贴水面的仍是照片底边）。上层用滚轮 / 触摸正常翻页，滚到照片环区域后滚轮继续推动照片环，点左上角 logo 可以回到顶部。点阵大字虽移到了上层，躲鼠标、悬停照片重组成章节名并染上照片颜色的交互都还在。开启系统的「减弱动效」时，光晕、倾斜、水面动画与鼠标涟漪都会关掉，只留一层很淡的静态水纹。

- **照片环**：滚轮、触摸拖动或方向键推动照片环，松手后带惯性停下；没人操作时会自己慢慢转，鼠标停在照片上时暂停。手机上先轻点照片预览中央粒子的章节文字和照片颜色，再点同一张或中间的「进入章节」才跳转；滑动仍用于推动照片环。桌面横屏时中间文字区横向缩到原来的 80%、纵向再收到 70%（`layoutRing()` 里的 `SCALE_X` / `SCALE_Y` 可调），两行照片和文字因此更紧凑，上下两条带仍无缝铺满；竖屏沿用原尺寸以免文字压到照片上。
- **点阵字**：鼠标靠近时点会散开、再弹回原位。悬停任意照片，点阵会重组成那一章的名字，并染上那张照片的颜色。
- **章节页**：横向惯性滚动，照片保持原始比例，带视差。底部的风格切换台可以把整章照片实时印成 `原图 / 油墨 / 网点 / 色块` 四种样子（键盘 1–4），色块模式会给出每张照片的 5 个主色。
- **单张大图**：在章节页点任意照片打开。点阵从缩略图里飞出来，由粗到细显影成照片；章节当前是油墨、网点或色块风格时，大图也显影成那个风格。鼠标变成放大镜（滚轮调倍数，放到足够大会直接显示原图像素），放大镜里永远是原片，旁边显示指针下的色号和这张照片的 5 个主色（点击复制）。← → 换张，1–4 换风格，Esc、Close 或点空白处关闭；手机上按住照片拖动看细节。网址会变成 `#/ch/章/张/view`，可以直接分享到某一张，浏览器返回键可以关掉大图。风格作品的署名显示在大图侧栏里。
- **声音**：进站默认开启；若浏览器限制自动播放，第一次触摸或按键时自动接通（滚轮不算），点顶部的 Sound 可以关掉，关闭后不会因后续触摸自动重新开启。整册只有一件乐器：**口琴（harmonica）**，全部由振荡器和噪声现场合成，依旧零音频文件。音色照自由簧片的物理特征搭：两片略微走音的簧片（湿调 −9 / +11 cents）互相拍频，`tanh` 软饱和把锯齿波尖角磨圆却保留丰富谐波，带通噪声做吹与吸的起音「chiff」和持续气流，1–3kHz 的共振峰给一点鼻音，长音后半段渐入喉颤，另有约 4.5–5Hz 的呼吸起伏；收尾是收气而不是断电。五声音阶沿用 `THEME.scale`，正好是十孔口琴第二把位。由此派生四种吹法：`V.harmonica` 长音与旋律、`V.tongue` 舌尖断气的短吐音、`V.harpChord` 同时含住几个孔的和弦、`V.breath` 没有音高的换气声。每章的环境声底层只留风 / 气 / 房间噪声，凡有音高的声音都由口琴发出；首页划过照片吹一个音，滚动照片环连成一段旋律。六章靠音区、气息、吐音与长音、和弦、速度区分：景德镇低音长音带压音，湖南中音短吐音，武林山风里的深喉颤，河南暖和弦，三亚高音明快循环，江西低音慢和弦托着长旋律。大图里每章有自己的一套声音（聚拢、显影、成像、切换、关闭各不相同），放大镜划过照片时会把指针下的亮度变成音高。

- **作者页**：顶部 About、首页署名和章节页署名都进入 `#/about`，沿用相册的蒂芙尼蓝幕布转场，展示作者和可直接跳转的社交图标。个人信息在 `THEME.author` 中配置。

## 本地运行

需要用本地服务器打开（直接双击 `index.html` 时，浏览器不允许读取照片像素：首页点阵字仍会用 `photos/tints.js` 里预先算好的色块染色，但风格切换和大图显影会失效）：

```bash
python3 -m http.server 8765
```

然后访问 http://localhost:8765 。字体来自 Google Fonts，首次打开需要联网。

> **必须在仓库根目录 `D:\travel-album-main` 下执行**，不要在 `photos/sq/` 或 `photos/full/` 里启动：那样服务器根目录只有 jpg、没有 `index.html`，浏览器会显示成「Directory listing for /」的文件列表，看起来像网页坏了。端口换成 8000 也没问题，关键是启动目录要对。本项目当前 8000 与 8765 两个端口都已指向仓库根目录，打开任意一个都能看到相册。另外不要直接双击 `index.html`（`file://` 下读不到照片像素）。

## 换照片

照片在 `photos/sq/`（640×640 方图，用在照片环上）和 `photos/full/`（长边 1600，用在章节页上），两边文件名一致。章节、照片和图注都在 `index.html` 顶部的 `CHAPTERS` 数据里；标题、首页大字、字体、音阶和动效参数在旁边的 `THEME` 里。整理好的照片可以用 `skills/photo-album/scripts/prepare_photos.py` 生成，它会顺带更新 `photos/tints.js`；手动替换了 `photos/sq/` 里的图，要再跑一次 `python3 skills/photo-album/scripts/bake_tints.py`。

照片允许 jpg / png 混用：非 jpg 的条目在 `CHAPTERS` 里加 `ext:".png"`，路径统一由 `photoURL(dir, src)` 拼接，键名（不含扩展名）同时对应 `tints.js` 的色块。`bake_tints.py` 会扫 jpg / png / webp；`w`、`h` 要填 full 图的实际宽高。

## 用你自己的照片做一个

仓库里带了一个 skill：[`skills/photo-album/`](skills/photo-album/SKILL.md)。把它和你的照片文件夹一起交给任何一个 agent（Claude Code、Codex、Cursor 等），它会按下面的步骤做出一个结构相同、风格属于你自己照片的网站：

1. 量照片：主色、明暗、冷暖、夜景比例，并生成一张缩略图总览；
2. 从这些数据里读出一份"风格 DNA"：纸色、强调色、字体、动效性格、粒子形态、风格台效果、音阶、每章的声音；
3. 用几个问题跟你确认；
4. 把 DNA 填进模板。

`index.html` 顶部标了「风格区」的地方是可变的，其余是引擎。skill 的原理和规则写在 `skills/photo-album/references/` 里。
