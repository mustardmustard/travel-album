# 风格 DNA：从照片里读出风格

同一套引擎，能做出截然不同的网站，靠的就是这份 DNA。DNA 是一份小 YAML，写在新站根目录的 `style-dna.yaml`。规矩是：

> **先有 DNA，再写代码。DNA 里每个决定都要写出处：来自哪张照片、哪个数字，或者用户的哪句话。**

写不出出处的决定，就是 agent 自己的口味，要删掉重想。

---

## 1. DNA 格式

```yaml
program: "一句话说清这次训练 / 这家馆"     # 用户确认过的那句话
venue: 场馆类型                            # 铁馆 / 综合馆 / 瑜伽馆 / 康复工作室；决定音阶、文字砖、语言混搭
portrait_release: "会员与教练均已签署肖像授权；未成年人照片已排除；仅用于本馆展示"   # 肖像授权，必填，见第 7 节
evidence:                            # 从 dna-seed.json 抄过来的关键数字
  tone: dark / contrast: hard / chroma: muted / temperature: cool / hue_spread: concentrated / night_share: .52 / portrait_share: .8
color:
  paper: "#0F1419"    # 出处
  ink: "#EAF0F4"      # 出处
  accent: "#F26A2E"   # 出处：哪张照片的哪个颜色，做了什么调整
  on_accent: "#0F1419"
type:
  display: Archivo    # Google Fonts，必须有 ≥700 的字重（点阵字要靠粗笔画取点）→ THEME.font.family、:root --display
  stretch: expanded   # 宽 / 正常 / 窄 → :root --stretch（125% / 100% / 62%）、THEME.font.stretch
  case: upper         # upper / mixed → :root --case（uppercase / none）、THEME.font.upper（true / false）
  cjk: Noto Sans SC   # 中文配字；馆名和口号里的英文走 display
  why: 为什么是这套字
hero: { word: GYM, sub: "Training / 26 / 11", line: "Deadlift · Glutes · Shoulders · Yoga" }
motion:               # 对应 THEME.motion；缓动曲线写在 :root --ease
  character: 利落 / 爆发 / 柔韧 / 机械 …
  drift: .0032  follow: .075  spring: .06  damp: .82  repel: 60  gather: 950  develop: 1250
texture:
  dots: circle        # 点阵字的粒子形态：circle / square / glyph / line（非 circle 要改 stepDots 的画法；这是旋钮，不算 swaps）
  styles: [orig, ink, dot, block]   # 风格台：原图 + 3 种，至少一种能给出调色板
sound:
  scale: [0,2,3,5,7,9,10]  # 多利亚；按训练强度 / 项目选，见 sound.md 第 3 节
  base: 57
  presence: .9        # THEME.presence：.5 若有若无 / .9 GYM 基线 / 1.5 有存在感
chapters:
  - { en: DEADLIFT, zh: 硬拉, exercise: 传统硬拉, body_part: 后链（臀·腘绳·背）, intensity: 极重·爆发, equipment: 杠铃·杠铃片·镁粉·腰带, mood: 重, line: "…", photos: [...], ambient: "124BPM kick 每拍 + offbeat open hat + sub 根音", voice: stab }
  # 每章的 mood 写这一章的训练质感词：重 / 持续酸胀 / 精准轻快 / 慢与呼吸
  # exercise / body_part / intensity / equipment 是识图得到的标签，写进项目 manifest
swaps: []             # 要替换的默认部件，最多 2 个，每个写清是哪条 DNA 跟默认部件冲突
```

## 2. 读照片的顺序

1. **跑脚本**：`prepare_photos.py`，再跑 `analyze_photos.py`。拿到 `dna-seed.json` 和 `contact.jpg`；同时把照片按训练项目分文件夹，生成项目标签 manifest（字段见第 1 节的 chapters）。
2. **看总览图 `contact.jpg`**，回答下面这些问题，答案写成笔记：
   - **动作**：杠铃、哑铃、绳索、自重、垫上伸展，各占多少？是发力瞬间、顶峰收缩还是组间休息？
   - **器械和身体部位**：画面里是杠铃、深蹲架、哑铃、龙门架还是瑜伽垫？主要练哪块（后链、臀腿、肩、核心、全身）？
   - **训练强度和场馆光线**：是大重量主项、辅助组还是收操？顶光、侧光、镜面反光、低光各占多少？脚本的 `night_guess` 只是猜，健身房低光加镜面亮斑常被误判成夜景，以看图为准。
   - **母题**：有没有反复出现的形状、颜色或物件？GYM 基线的母题是"杠铃片、护腕、地垫边缘的橙"。母题最适合拿来定强调色和章节，器械品牌 logo 不算母题（见第 7 节）。
   - **质感**：胶片、数码、手机还是监控截图？颗粒、锐度、色偏怎样？有没有汗渍、镁粉、镜面反光？
   - **拍照的人在看什么**：全身动作、局部特写、仰拍还是平视？竖幅占多少（`portrait_share`，影响 640×640 裁切）？
3. **识图定项目标签**：按下面的线索表给每张照片打 `exercise / body_part / intensity / equipment`，写进项目 manifest。项目标签是后面分章和配声音的依据，不要只按颜色分。

   | 画面线索 | 训练项目 | 备注 |
   |---|---|---|
   | 瑜伽垫、伸展体式、赤足、平衡与呼吸姿态 | 瑜伽 YOGA | 收操、低强度、留白 |
   | 杠铃离地、髋铰链、镁粉、腰带、硬拉台 | 硬拉 DEADLIFT | 主项、最重、爆发、低频 |
   | 深蹲架、臀推凳、腿举机、杠铃在肩上 | 臀腿 GLUTES | 下肢辅助、持续酸胀 |
   | 哑铃侧平举、推举、绳索面拉、龙门架 | 肩部 SHOULDERS | 上肢、精准轻快 |
   | 跑步机、跳绳、划船机、动感单车 | 有氧 | 不是推荐 4 章之一；照片多时单列一章，少时并入相邻章 |
4. **起草"一句话"**：这次训练 / 这家馆是什么？例如"在城市综合馆，从最重的一组硬拉收在最后一个呼吸"。后面所有决定都要能回到这句话上来。
5. **按下面的映射表**，逐项填 DNA。

## 3. 映射表：数字和观察 → 设计决定

每一条都写了"为什么"。遇到表里没有的情况，按"为什么"去推。

### 3.1 颜色

**强调色 accent**

| 规则 | 为什么 |
|---|---|
| 只从 `accent_candidates` 或某张照片的 `vivid_spots` 里选 | 原理 1 |
| 优先选**母题**的颜色：在几个章节里都出现、或者最能代表这家馆的颜色 | 它会出现在 logo、文字砖、点阵字、油墨效果里，是整个站的签名 |
| 可以把饱和度和明度提高，让它在纸上站得住；色相偏移不超过 ±8° | 照片里的颜色经过光线和压缩会发灰，提纯以后仍然是"那个颜色" |
| 在 paper 上做大字时，对比度要 ≥ 3:1 | `on_accent` 选 paper 或 ink 里对比更高的那个 |
| 跳过器械品牌 logo、补剂罐、工服标识的商标色 | 商标色是品牌资产，不是这家馆从照片里长出来的气质（见第 7 节） |

示例：GYM 基线从护腕与杠铃片边缘的 `#E2642C`（色相 18°）提纯成 `#F26A2E`。

**纸和墨 paper / ink**

| 证据 | 决定 | 为什么 |
|---|---|---|
| `tone` 是 bright 或 mid，`night_share` < .5 | 浅色纸，用 `paper_light` | 照片是主角，浅纸最不抢戏 |
| `tone` 是 dark，或 `night_share` ≥ .5 | 深色纸（`paper_dark_option`），墨变浅色 | 低光器械放在白纸上会像一个个黑洞；深色底让顶光和镜面高光发亮 |
| `temperature` 是 warm 或 cool | 纸带一点同向的色温，偏离纯白不超过 6 | 让外壳跟照片站在同一种光线下 |

健身房低光加镜面亮斑常被 `night_guess` 判成夜景，`night_share` 会偏高，`paper_ink` 因此给出深色纸候选。要不要用深色纸以看图为准：镜面高光不是夜景光源，但低光器械压在深底上确实更稳，别顺手把它当成夜景题材去配色（详见第 7 节）。

**整组照片的色相分布 hue_spread**

| 证据 | 决定 | 为什么 |
|---|---|---|
| varied（照片颜色四散） | 外壳更克制：一个强调色，其余全中性 | 照片已经够吵了 |
| concentrated（照片几乎是一个色系） | 两种选法：<br>1. 强调色取这个色系里最纯的一点，做成近似单色的站；<br>2. 取照片里罕见的对比色点，前提是它确实在照片里出现过 | 要么顺着照片走，要么从照片里找反差，都不能凭空加色 |

### 3.2 字体

| 训练质感 | display 方向 | Google Fonts 例子 |
|---|---|---|
| 力量、大重量、工业器械 | 宽体无衬线，全大写 | Archivo（wdth 125）、Unbounded、Syne |
| 爆发、速度、高强度间歇 | 窄体或压缩的粗无衬线 | Archivo（wdth 62）、Big Shoulders Display、Anton |
| 柔韧、瑜伽、呼吸、收操 | 人文衬线或圆润无衬线，大小写混排 | Fraunces、Young Serif、DM Serif Display、Nunito |
| 团课、社群、活泼 | 粗圆体或胖体 | Rubik、Baloo 2、Bricolage Grotesque |
| 复古铁馆、旧海报、胶片感 | 等宽或打字机体 | Space Mono、IBM Plex Mono、Courier Prime |

**硬性要求**
- 首页点阵大字用 `THEME.font`，字重必须 ≥ 700。笔画太细的话，`wordPoints` 取不到足够的点，字会散。
- 中文配 Noto Sans SC 或 Noto Serif SC，跟 display 的衬线与否保持一致；馆名和口号里的英文直接走 display。
- 只用一套 display 加一套正文（或者 display 兼任正文），不要三套。

### 3.3 动效（THEME.motion）

| 性格 | 证据（训练质感） | drift | follow | spring / damp | repel | gather / develop |
|---|---|---|---|---|---|---|
| 利落·力量（GYM 基线） | 硬拉、大重量主项，反差 normal 或 hard | .0032 | .075 | .06 / .82 | 60 | 950 / 1250 |
| 爆发 | 跳箱、冲刺、HIIT，contrast hard | .0045 | .10 | .085 / .78 | 55 | 800 / 1000 |
| 柔软·柔韧 | 瑜伽、拉伸、呼吸，反差 soft | .0018 | .05 | .035 / .88 | 75 | 1200 / 1700 |
| 漂浮 | 留白、汗雾、镜面反光，tone 偏亮、低饱和 | .0012 | .04 | .025 / .92 | 85 | 1400 / 2000 |
| 机械·工业器械 | 器械节奏、组间计数、钢架与流水线 | .005 | .11 | .09 / .74 | 50 | 750 / 900 |

`repel` 是点阵字躲开鼠标的半径（px）：性格越软，半径越大，散开的范围也越大。

缓动曲线 `:root --ease` 跟着变，JS 会自动读取它：
- 利落 / 力量：`cubic-bezier(.7,0,.2,1)`
- 爆发：`cubic-bezier(.8,0,.2,1)`，起段更陡
- 柔软 / 柔韧：`cubic-bezier(.4,0,.2,1)`
- 机械 / 工业器械：`steps()`，或者 `cubic-bezier(.9,0,.1,1)`

### 3.4 质感：点阵粒子和风格台

| 证据 | 粒子形态 | 风格台的 3 种效果 |
|---|---|---|
| 力量、器械铭牌、印刷感（GYM 基线） | circle | 油墨双色、网点、色块 |
| 低光、镜面高光，`night_share` 高 | circle（发光） | 网点、扫描线、色块 |
| 柔韧、瑜伽、自然光 | circle 或 line | 蓝晒 cyanotype、木刻双色、色块 |
| 爆发、高强度、高饱和 | square | 像素马赛克、riso 双色、色块 |
| 复古铁馆、胶片 | glyph（字符） | ASCII、颗粒油墨、色块 |
| 线条、拉伸姿态、极简 | line | 线稿（边缘检测）、单色网点、色块 |

规则：
- "色块"（k-means 调色板）建议永远保留。它是"照片是原材料"最直接的证明，大图侧栏的调色板也跟它呼应。
- 新效果的写法见 `components.md` 的"风格台"一节。

### 3.5 声音

详见 `sound.md`，这里只列 DNA 级别的决定：
- **音阶**：按训练强度 / 项目选（`sound.md` 第 3 节）。推荐多利亚 `[0,2,3,5,7,9,10]` 或自然小调，重项目偏小调色彩，收操可转明亮。
- **整体速度**：跟着动效性格走。欧美动感 house / EDM 底鼓 124 / 126 / 128 BPM 四四拍（硬拉 / 臀腿 / 肩部），瑜伽章降到 100 BPM 的 chill / downtempo。
- **每章的乐器**：跟着那一章的训练质感走（硬拉=kick 每拍 + sub 根音，臀腿=offbeat bass 切分 + 反拍 stab，肩部=clap + lead 短句，瑜伽=长 stab / pad + air 气息与留白）；`VOICE` 悬停音统一用 lead / stab 短音。
- **presence**：环境声的总音量，填进 `THEME.presence`（.5 若有若无，.9 GYM 基线，1.5 有存在感）。门店大屏常年无人交互时，在 `THEME.soundOn` 上默认关声，而不是只压低 presence。

### 3.6 首页和文案

| 项目 | 规则 |
|---|---|
| `hero.word` | 馆名，或者一句能概括这次训练的口号。最好不超过 9 个字母，超过时要带空格，`wordPoints` 会拆成两行。用户的母语不是拉丁字母时，也优先用拉丁字母大字，点阵效果最好；本地文字放进文字砖 |
| `hero.sub` | `Training / YY / MM` 这类格式，信息要短 |
| `hero.line` | 训练项目列表，用 `·` 连接（如 `Deadlift · Glutes · Shoulders · Yoga`） |
| `TEXT_TILES` | 两块：a 是强调色底，放一句英文口号；b 是墨色底，放本地文字和统计数字（组数、次数、章节数） |
| 章节导语 | 一句话，用第一人称的训练感受，不做动作说明 |
| 图注 | 16 个字以内，写训练感受，**不写动作要领、不做教学示范**，也不写"这是 XX" |

图注不做教学示范的理由见第 7 节。

## 4. 章节怎么分

- **推荐 4 章 × 4 张 = 16 张**：每章 1 张氛围/器械图（空镜、器械、场馆光线）+ 3 张动作图。照片不足时按比例缩，每章至少 2 张；宁可少分一章，也不要出现只有 1 张的章。
- **按训练项目分，不按拍摄日期或组次流水账分。** `dna-seed.json` 里的 `chapter_draft_by_color` 只是按颜色粗分的辅助信号；`exercise_draft_by_label` 才是按项目标签分出来的正式草案（`--out` 下没有 `chapters.json` 时它是空数组）。最终要结合识图得到的动作、器械、身体部位、训练强度重新分（见第 2 节的识别线索表）。
- 每章起一个英文项目名（en）、两个汉字（zh，或用户的语言），再配一句导语。
- **顺序按一次训练的流程走**：主项 → 下肢辅助 → 上肢 → 收操，强度和音量由重到轻。推荐顺序：硬拉 DEADLIFT → 臀腿 GLUTES → 肩部 SHOULDERS → 瑜伽 YOGA。有氧照片多时可单列、插在主项之后；少时并入相邻章。

## 5. 跟用户确认：最多 4 个问题，一次只问一个

每个问题都带 agent 的推荐答案和理由，用户可以只回答"按你的来"。

1. **"这家馆主要练什么、这次展示想传达什么？"** 附上 agent 起草的那句话（写进 `program`），以及据此定的 hero.word、hero.sub 和 4 个项目标签的顺序。
2. **"章节这样分可以吗？"** 列出每章的项目名、训练质感词和照片编号（对应 contact.jpg 上的编号）。
3. **"风格选 A 还是 B？"** 给两套 DNA 方向，每套用 3 行描述：
   - 色板，写成 `paper / ink / accent`，accent 注明出处；
   - 字体和动效性格；
   - 声音（音阶加两种代表乐器，如底鼓、stab、lead、sub bass）。

   A 贴近照片本来的训练质感，B 往器械母题或反差上更大胆一些。
4. **"声音要有存在感，还是若有若无？"** 门店大屏场景顺带确认是否默认关声。

用户已经在需求里说清楚的问题，跳过不问。

## 6. 防撞衫检查（定稿前必须做）

把 DNA 跟模板原始站的 GYM 基线 DNA（见 `examples.md` A）逐项对比：paper、accent 色相、display 字体、动效性格、粒子形态、风格台效果、音阶、主要乐器。

- **至少 4 项要不同。** 做不到的话，说明你在套模板而不是在读照片，回到第 2 步重看。
- 唯一的例外：照片确实也是同一家综合馆、同样按这 4 个项目分章。这时也要在母题、强调色或章节上找到不同点。
- 防撞衫基准已从 JAPAN 更换为 GYM 基线，对照时以 `examples.md` A 为准，不要跟旧基准比。

## 7. 健身房展示的专属规则

这几条是健身照片一定会碰到、通用相册不会预设的，起草 DNA 和填站时都要过一遍。

### 7.1 肖像授权

- 画面里有会员、教练或路人时，先拿到书面 consent；未成年人照片一律排除，不做"裁掉脸"这种折中。
- DNA 顶层必填 `portrait_release`，写清谁授权、授权范围（仅本馆展示 / 可对外 / 期限）。
- `CHAPTERS` 里人像照片的 `credit` / `license` 扩展成授权说明：例如 `credit: "会员 · 已授权"`、`license: "肖像授权：仅限本馆展示，2026-11"`；第三方摄影作品另写作者与许可。
- 拿不到授权就换成器械空镜、局部特写或背影，并在 `portrait_release` 里注明"本册无未授权人像"。

### 7.2 品牌 logo 与器械商标

- 照片里常有器械品牌、补剂罐、教练工服的 logo。它们不是"母题"，强调色不能从商标色里取：原理 1 要求从像素提纯，但商标色是品牌资产，不是这家馆的气质。
- 处理：要么在构图里避开或虚化，要么保留但选强调色时跳过这些色块；需要商用时另行确认商标使用授权。
- `TEXT_TILES`、馆名、`hero.word` 也不要照搬品牌名。

### 7.3 低光、镜面、竖幅占多数

- 健身房常是低光加顶光/镜面亮斑，`night_guess`（整体暗但有亮光源）会把它们大量判成夜景，`night_share` 偏高，`paper_ink` 会给 `paper_dark_option`。以看图为准：镜面高光不是夜景灯，但低光器械压在深底上确实更好看，所以深色纸往往是合理选择，只是别顺手把它当成夜景题材去配音色和文案。
- `portrait_share` 通常很高（全身动作、镜前自拍）。`photos/sq` 是 640×640 居中裁切，竖幅全身动作容易切掉头脚；浓缩短图前先看构图，必要时把关键动作放到画面中段。
- 镜面会拍到拍摄者和多余人像，识图时一并计入肖像授权检查。

### 7.4 图注不做教学示范

- 图注和章节导语写训练感受（"最后一组，手已经不听使唤了"），不写动作要领、组数次数、角度和发力提示。
- 原因：一是风格上第一人称感受才对（§3.6）；二是避免把展示当成教学、产生动作误导和安全责任；三是每个人的动作标准不同，写死了反而不准。
- 需要教学信息时放场馆自己的物料，不放进展站。
