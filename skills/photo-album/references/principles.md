# 五条原理

这个展示看起来是"照片环 + 点阵字 + 横滑章节 + 大图 + 声音"，但这些只是外形。把外形拆掉，剩下的是下面五条。做别人的健身房照片展示时，部件可以换，这五条不能丢。

每条都写了：它是什么、本站怎么做到的（代码里的位置）、怎样算违反、怎么自查。

---

## 1. 照片是唯一的原材料

**是什么**：页面上所有"有颜色、有形状、有声音"的东西，都从照片的像素里算出来。不额外找素材，不凭感觉手调颜色。

**本站怎么做到**

| 效果 | 来源 | 代码 |
|---|---|---|
| 强调色 `--accent`（GYM 基线为器械橙） | 从照片主色里提纯（GYM 基线：护腕和杠铃片边缘的橙，色相约 18°，提纯成 `#F26A2E`） | `:root` |
| 悬停照片时，点阵字染成那张照片的颜色 | 把照片铺在点阵字后面，逐点取色 | `photoTint`、`tintAt`、`setShape` |
| 风格台的油墨、网点、色块三种效果 | 实时读像素，重新印一遍 | `fxInk`、`fxDot`、`fxBlock` |
| 大图的 5 个主色 | 对原片做 k-means | `lbPalette` |
| 大图显影时每一级点阵的颜色 | 图像金字塔求格子平均色 | `pyramid`、`shrink`、`lbLevel` |
| 放大镜划过时的音高 | 指针下的亮度映射成音级，饱和度映射成力度 | `lpListen` |

**怎样算违反**
- 用一套跟照片无关的流行配色，比如紫粉渐变；
- 用图标库、插画或贴纸当装饰；
- 用固定颜色的粒子；
- 用 mp3 当背景音乐；
- 拿器械品牌的 logo 或商标色当强调色，而不是从照片像素里提纯。

**自查**：页面上随便指一个颜色，都能说出它来自哪张照片。

## 2. 外壳克制，把舞台让给照片

**是什么**：界面只有纸、墨、一个强调色、一套 display 字体。界面本身几乎不说话，照片是主角。

**本站怎么做到**
- 只有 4 个颜色 token：`--bg` 暖白纸、`--ink` 近黑、`--accent` 照片里来的强调色、`--on-accent`。
- 字体：Archivo 宽体全大写，用在导航、项目编号、组次标签；中文配 Noto Sans SC。
- 照片保持原始比例，不加圆角、阴影或滤镜；图注一句话就够，写训练感受，不写动作要领。
- 第三方作品与肖像授权的署名只出现在大图侧栏，不压在照片上。

**怎样算违反**
- 第二个、第三个强调色；
- 渐变背景或毛玻璃；
- 卡片阴影；
- 把照片裁成统一比例（首页环的方图是例外，它是"缩略"）；
- 每张照片下面堆满元信息，或者把图注写成教学示范。

**自查**：把所有照片换成灰色方块，页面应该显得很空。

## 3. 一切都有物理感

**是什么**：东西不是"出现"的，是被推过来、飞过来、慢慢显出来的。有惯性、有回弹、有过程。

**本站怎么做到**

| 效果 | 做法 | 代码 |
|---|---|---|
| 照片环 | 目标值加插值（`ring.u` 追 `ring.tu`），松手后带惯性；没人操作时自己慢慢转 | `nudge`、`loop` |
| 点阵字躲鼠标 | 弹簧加阻尼回到原位 | `stepDots` |
| 章节横滑 | 同样的追赶插值，再加视差 | `renderChapter` |
| 大图打开 | 粒子沿二次贝塞尔曲线从缩略图飞出，到位时轻轻冲过头（`easeBack`），随后点阵由粗到细分 7 级显影，相邻两级交叉淡化，最后淡入原片 | `lbDrawDots`、`lbDrawDev` |
| 放大镜 | 位置和倍数都带一点追赶 | `LP` 的 lerp |
| 页面转场 | 幕布 | `curtain` |

**怎样算违反**
- `display:none` 硬切；
- 线性缓动；
- 所有元素同时出现，没有错峰；
- 动画结束时生硬一停，没有余量。

**自查**：开启 `prefers-reduced-motion` 时，这些都要退化成直接切换，并且仍然可用（`reduce` 变量）。

## 4. 每一章是一种训练质感，质感落在三个层面

**是什么**：章节不是"照片分组"，是一种训练质感：硬拉的重与爆发、臀腿的持续酸胀、肩部的精准轻快、瑜伽的慢与呼吸。同一种质感要同时落在画面、交互、声音三个层面。

**本站怎么做到**

| 层面 | 落在哪里 | 代码 |
|---|---|---|
| 画面 | 章节名（中英项目名）、一句导语、照片顺序（1 张氛围/器械图 + 3 张动作图） | `CHAPTERS` |
| 交互 | 首页悬停时，点阵字重组成章节名并染上照片色 | `hoverChapter` |
| 声音 | 每章一种环境声、一种悬停音色、一套大图事件音 | `SCENES`、`VOICE`、`LB_SND` |

举一章为例：硬拉章是 124 BPM 的 kick 每拍加 sub 根音，悬停音色是 sub 短音，大图打开时有一声 sweep 上扬、成像时一声 impact；瑜伽章降到 100 BPM，只留长 stab / pad、air 气息和留白。本站七章各有质感：前四章按一次训练流程排（硬拉最重最低、臀腿律动最密、肩部最轻快最亮、瑜伽最慢最轻），后三章是减脂 132 BPM 的冲刺、舞蹈 130 BPM 的 house 律动、普拉提 92 BPM 的控制。加章时 `SCENES`、`VOICE`、`LB_SND` 必须同步加项，否则「每章一种质感」在那一章就断了。

**怎样算违反**
- 章节按拍摄日期或"第几组"流水账机械地切分；
- 每章的声音只是换了音高；
- 章节名起成 "Day 1" 或 "IMG_0231"；
- 只看照片颜色分章，不看动作和器械。

**自查**：闭上眼听，能分出现在是哪一章、是重还是轻。

## 5. 单文件、零构建、零音频文件

**是什么**：整个网站就是一个 `index.html` 加 `photos/` 文件夹。不用打包工具和框架，不放音频文件。声音全部用 Web Audio 现场合成。

**本站怎么做到**
- 原生 HTML、CSS、JS 写在一个文件里，只从 Google Fonts 加载字体。
- 合成乐器：
  - kick 底鼓、clap 拍手、hi-hat、sub 低频、bass 律动贝斯、和弦 stab、明亮 lead、riser / sweep、impact、噪声；
  - 卷积混响（节拍要干净，混响由 4.2s 缩到约 1.2s、wet 约 .2、预延迟约 12ms）；
  - 总线压缩，防止爆音。
- 遵守浏览器规则：
  - 第一次点击或按键才开声音（`sndFirst`），滚轮不算；
  - 尊重 reduced-motion；
  - 用 `file://` 打开时不能读像素：首页染色退回预烘的 `photos/tints.js`，风格台和大图要求用本地服务器打开；
  - 门店大屏常年无人交互时，`THEME.soundOn` 默认设为 false，由第一次点击开启。

**怎样算违反**
- 引入 React、Vite 之类需要构建的东西；
- 放一首 mp3 或一段 EDM loop 音频文件；
- 进页面自动播放失败后不处理；
- 依赖后端。

**自查**：执行 `python3 -m http.server`，打开页面，所有功能都可用。
