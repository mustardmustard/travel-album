# 声音：全部现场合成

声音不是背景音乐，它是训练质感的第三个层面（原理 4）。整个站不放任何音频文件，所有声音都用 Web Audio 在浏览器里现场合成（原理 5）。本册的方向是**轻快钢琴**：整站只有一台钢琴——没有鼓、没有贝斯、没有采样。「轻快」由三件事拼出来：触键短（断奏多）、泛音亮（`bright` 抬高）、音型活（上行/下行的跑动与琶音）。七章靠音区、触键、音型与速度区分，不靠换乐器。

钢琴不是采样：每个音由带非谐性的正弦泛音叠成（`f_k = k·f·√(1+B·k²)`，B≈0.00035，真实钢琴中音区量级），起音叠一口极短的槌触噪声，越高泛音衰减越快——这是它听起来像「弦被槌敲」而不是「合成器」的关键。

## 1. 硬规则

- **开启时机**：`THEME.soundOn` 默认开启。若浏览器允许自动播放，加载后直接接通；否则在首次 `pointerdown`、`pointerup`、`touchend` 或 `keydown` 时恢复播放（`sndFirst`）。触摸结束事件用于兼容移动浏览器。滚轮和悬停不算用户操作。顶部的 Sound 按钮可以关掉，关闭后后续手势不会自动重新开启。门店大屏、前台展示这类常年无人交互的部署，把 `THEME.soundOn` 设为 false，由第一次点击开启，不要依赖自动播放。
- **启用与播放分开**：`SND.on` 是用户的开关选择，`sndReady()` 判断音频是否实际运行。只有 `sndReady()` 为真时才排声音，避免在浏览器暂停自动播放时积压音符。均衡器只在实际播放时跳动。
- **总线**（`sndInit`）：
  - `SND.out` 接压缩器（threshold -16、ratio 8），再接扬声器，作用是防爆音，保留不动；
  - `SND.fx` 走悬停音、转场和大图音；
  - `SND.lp` 是章节环境声，前面有一个低通滤波器；
  - `SND.wet` 是卷积混响。轻快钢琴取中等偏短的 **2.0s** 房间、wet 约 **.34**、预延迟约 18ms：比空灵慢板的 4.2s 收得干净，又比鼓组时代的 1.2s 多一点琴房空气感。断奏一多，长混响会糊成一片，`pianoRun` 的颗粒感全靠这条尾巴不拖。
- **音阶与音量**：GYM 基线 `THEME.scale = [0,2,4,7,9]` 大调五声、`base = 62`、`presence = 1.1`。大调五声没有半音，怎么跑都不刺；钢琴比鼓组轻，`presence` 稍抬一点，让七章的音型听得清。
- **让位**：打开大图时，`sndDuck(true)` 把环境声压到 30%，并让它变闷（低通 1400Hz——别再往下压，把钢琴闷死就听不出是钢琴了）。
- **切走标签页再回来**时，不补放积压的音（`sndTick`）。
- **零音频文件**：钢琴、槌触噪声、气声全部用振荡器和噪声缓冲现场合成，不塞钢琴采样、音源或 loop（原理 5）。
- **音量预算**：参照本站实测，打开大图那几秒的峰值在 0.10–0.32 之间，各章之间相差不超过 3 倍。钢琴的力度由触键方式决定：`pianoChord`（多音叠加）天然比 `pianoTouch`（单音断奏）响，某一章明显偏响时降这一章的 `v` 或减少一次同时落下的音，不要动总线压缩器。
- **数组对齐**：`LB_SND`、`VOICE`、`SCENES` 都按下标取 `CHAPTERS`。本站 7 章就是 7 项，加章必须三处一起加，否则新章 `SCENES[ci]` 为 `undefined`、`VOICE[ci]` 会抛错。
- **环境声总音量**：`THEME.presence`，对应 DNA 的 `sound.presence`。整册没有鼓撑底，环境声就是章节里的「主奏」，别轻到听不出章与章的差别。

## 2. 乐器表（`V.*`）

主乐器都加在 `Object.assign(V, {...})` 里，签名统一 `(f?, t, dest, v, ...)`。钢琴族的公共选项 `o`：`bright`（泛音亮度倍率，1 = 中音区原生）、`breath`（槌触噪声量）、`vib`（轻微揉弦）、`soft`（压低泛音、放慢起音，做「贴键」的柔音）、`bend`（起音滑音）。

| 乐器 | 签名 | 音色 | 适合的训练质感 |
|---|---|---|---|
| `piano` | `(f, t, dest, v=.06, dur=.5, o)` | 基础琴音：六个非谐泛音各自衰减 + 槌触噪声 | 低音起手、和弦根音、慢一点的章 |
| `pianoTouch` | `(f, t, dest, v=.08, o)` | 断奏：短、亮、几乎没有踏板（`piano` 的短促版） | 跑动音型、节奏点——「轻快」的主要来源 |
| `pianoChord` | `(freqs, t, dest, v=.05, dur=.5, o)` | 和弦：几个音先后 9ms 落下，像手指不是绝对齐的 | 成像、收句、稳定感的章 |
| `pianoRun` | `(degs, t, dest, v=.055, gap=.085, oct=1, o)` | 一串上行/下行的断奏 | 章节的性格音型：谁跑得快、谁跑得慢 |
| `air` | `(t, dest, v, dur, f0, f1)` | 柔和气声 | 瑜伽章的呼吸与气息 |

辅助层保留：
- `swoosh(...)`：页面转场的风声（引擎里，一般不改）；
- `wind(...)`：可调噪声扫频；
- `loopNoise(dest, buf, type, freq, q, gain)`：循环噪声，做场馆底噪、通风声、镜面空间感——它只出现在 `SCENES` 的**底层**，音量要很小（.012–.016），别盖过琴声；
- `lfo(param, rate, depth)`：让噪声底层的音量慢慢起伏，场馆的"呼吸感"。

**新乐器**：需要表里没有的音色时，比如拨弦、八音盒、muted 弱音，就在 `Object.assign(V, {...})` 里加一个。写法跟现有乐器一样：
- 签名统一是 `(f?, t, dest, v, ...)`；
- 用 `env()` 包络；
- 用 `t` 排程，不用 `setTimeout`；
- 每个源都要 `stop`。

几个常用的合成法：

| 音色 | 做法 |
|---|---|
| 琴音 `piano` | 6 个正弦泛音，频率 `k·f·√(1+B·k²)`（B≈0.00035），越高衰减越快；起音叠 `breath` 量的槌触噪声 |
| 断奏 `pianoTouch` | `piano` 收短到 .24s、`bright` 1.3、`breath` 减半——「轻巧地弹」 |
| 和弦 `pianoChord` | 每个音错开 9ms 落下，`v` 按 √音数 分摊 |
| 跑动 `pianoRun` | `pianoTouch` 按 `gap` 间隔串一列音级 |
| 贴键柔音 | `soft` 选项：压低 2 次以上泛音、放慢起音，配 `air` 就是瑜伽章 |
| 气息 `air` | 带通噪声慢扫，`v` ≤ .03，只在慢章出现 |

## 3. 音阶：按训练强度和项目选

`THEME.scale` 是一个八度里的半音位置，`THEME.base` 是 MIDI 基准音。`hz(音级, 八度, 基准)` 会自动按音阶取音，所以换了音阶，整站的旋律都跟着换。整册只放一条主音阶，靠每章的音区、音型和速度区分；`THEME.scale` 是全局的，不要按章改。GYM 基线固定 `[0,2,4,7,9]` 大调五声、`base = 62`、`presence = 1.1`。

| 训练强度 / 项目 | scale | 备注 |
|---|---|---|
| 轻快、明亮、跑动多（默认推荐） | `[0,2,4,7,9]` 大调五声 | 没有半音，断奏连跑都不刺；「轻快」的首选 |
| 大重量主项、铁馆、要一点分量 | `[0,2,3,5,7,9,10]` 多利亚 | 小调底色里有一个大六度，低音起手更沉 |
| 爆发、HIIT、冲刺 | `[0,3,5,7,10]` 小调五声 | 音少、落点密，适合最快的 `pianoRun` |
| 康复、评估、冷静 | `[0,2,4,7,9]` 大调五声 + `soft` 触键 | 平和，不 pushing |

`base` 的选法：重、沉的项目取 55–60，明亮轻快的取 60–67。GYM 基线取 62。

音阶按**训练强度 / 项目**选，不要拿地域性音阶当正面示例：健身房展示听的是触键和节奏，不是地域色彩。

注意：音阶长度会影响"音级"的含义。五声音阶里音级 5 就是高八度；七声音阶里，高八度是音级 7。`lpListen` 把亮度映射到 0–9 级，在五声音阶里大约覆盖两个八度，不用改。

## 4. 每章三套声音

三个数组的顺序都对应 `CHAPTERS`，写在「声音：风格区」里，项数必须相等。本站 7 章：硬拉 DEADLIFT → 臀腿 GLUTES → 肩部 SHOULDERS → 瑜伽 YOGA → 减脂 CUTTING → 舞蹈 DANCE → 普拉提 PILATES。新站可以按需增减章数，但每章都要有对应的一项。

### 4.1 环境声 `SCENES[i] = b => ({ nodes, tick })`

环境声 = **底层** + **事件层**。

- **底层**：放进 `nodes` 的持续声源，切章时会自动停掉。轻快钢琴册的底层只有很轻的 `loopNoise`（场馆气声），凡是有音高的声音都由钢琴发出。
- **事件层**：`tick(t)` 在时间 `t` 排一个或几个音，然后返回下一次的时间。`tick` 一次排满一个小节（4 拍）再返回下一小节起点，节拍不受 60ms 调度抖动影响。音型按 BPM 定拍，可以用 `bar` 计数让每两小节换一个花样，但别用随机数打乱拍点。

GYM 基线 7 章的拆解，可以照这个思路举一反三：

| 章（项目） | 底层 | 事件层（全是钢琴） | 节奏 |
|---|---|---|---|
| 硬拉 DEADLIFT | 低通气声 + 慢 LFO | 低音八度与和弦交替，偶数小节尾一次短跑动 | 108 BPM，最低最稳 |
| 臀腿 GLUTES | 很轻的通风气声 | oom-pah 分解和弦，四组和声循环 | 116 BPM，律动最密 |
| 肩部 SHOULDERS | 带通气声 | 高音区亮断奏连续十六分 | 126 BPM，最亮最跳 |
| 瑜伽 YOGA | 低通气声 + 慢 LFO | `soft` 和弦 + 慢跑动 + 偶尔一声 `air`，大量留白 | 88 BPM，最留白 |
| 减脂 CUTTING | 明亮带通气声 | 最快的十六分音阶跑动 + 低音每两拍一次 | 138 BPM，最急最快 |
| 舞蹈 DANCE | 中频气声 | 切分断奏（反拍错开半拍）+ 低音每拍 | 128 BPM，最俏 |
| 普拉提 PILATES | 低通气声 | 匀速单音与和弦交替，像数拍子 | 100 BPM，最有控制感 |

配方原则：
- **速度按训练质感排，不必是一条单调的递减曲线**：前四章走「一次训练」由重到轻，后三章是三种项目性格（冲刺 / 律动 / 控制）。都在「轻快」这一档里变化——瑜伽 88 BPM 也仍是明亮的短音，只是留白多。
- 区分章与章靠**音区（低音起手还是高音跑动）、触键（`piano` 还是 `pianoTouch`、开不开 `soft`）、音型（和弦交替 / 分解 / 跑动 / 切分）**三件事，每章至少在两件上跟相邻章不同。
- **底层决定"在哪练"，事件层决定"这一章什么质感"**。比如：
  - 铁馆力量区 = 低通气声 + 低音八度起手；
  - 镜面舞蹈房 = 中频气声 + 高音区切分断奏；
  - 瑜伽房 = 低通气声 + `soft` 和弦与 `air` 气息、大量留白。
- 全部现场合成：槌触噪声和泛音是振荡器与噪声缓冲拼出来的，不要塞钢琴采样或音源（原理 5）。

### 4.2 悬停音色 `VOICE[i] = (f, t, dest) => …`

首页悬停某章的照片时，用这一章的触键弹一个音。GYM 基线里七章都是钢琴，只是触键、音区、亮度和单音/和弦不同（低章用 `piano` 长一点，高章用 `pianoTouch` 短而亮，舞蹈章给双音）。

悬停音触发得最频繁，最容易刺耳，所以有几条额外规矩：
- **音高由照片决定**：`sndHover` 用 `photoLum` 读照片的平均亮度，暗照片低、亮照片高（音级 0–7）。不要用"第几章、第几张"去算音高。
- **不往上翻到 1–4kHz**：那是人耳最敏感的频段。要升八度时用 `hz` 把八度参数加 1，超过 900Hz 就不升。
- **用短触键**：悬停一律 `pianoTouch` 或短 `piano`（`dur` ≤ .6），`v` 乘 0.3–0.5；别用满力度长音。
- **音量按实测响度拉平**：`pianoChord` 多音叠加的峰值天然比单音高，按 RMS 拉平后别让某一章的悬停音比别的章响一截。
- 悬停音走 `SND.hov` 总线，上面有一道 3.6kHz 的柔和低通；两次触发至少间隔 90ms。

### 4.3 大图事件音 `LB_SND[i] = { open, step, done, look, swap, close }`

GYM 基线里 `LB_SND` 用 `pianoChord(open)`、`pianoTouch(step)`、`pianoChord(pianoRun)(done)`、`pianoTouch(look/swap)`、下行 `pianoRun(close)`。

| 事件 | 时机 | 写法 |
|---|---|---|
| `open(t)` | 粒子开始聚拢 | 低音起手 + 一个亮和弦落下，重一点的章低八度，轻的章配一声 `air` |
| `step(t, j)` | 显影每升一级，j = 0–6 | `pianoTouch` 点 7 下，音级随 j 上行、力度很小；7 级连起来是一条上行音阶 |
| `done(t)` | 成像完成 | 一个宽和弦 + 尾上一个高音，是整套里最"满"的一声 |
| `look(t, d, v)` | 放大镜划过；d = 亮度对应的音级（0–9），v = 饱和度对应的力度 | `pianoTouch` 的短点音，`v` 乘一个很小的系数，因为会频繁触发 |
| `swap(t)` | 左右切换照片 | 一小段上行或下行 `pianoRun` 做过渡 |
| `close(t)` | 关闭，粒子飞回 | 一段下行 `pianoRun`，跟 `open` 呼应 |

`arp(t, 音级数组, 间隔, (音级, 时间) => …)` 用来写琶音。

七章的事件音各有性格：跑动音列的长短、方向、`bright` 高低都不同，别让相邻两章听感一样（原理 4）。

## 5. 首页的声音：`RING_SND`

在「声音：风格区」的最前面：
- `melody`：照片环每滚过一格，弹旋律里的下一个音级，自动高一个八度；
- `step`：弹旋律的乐器，GYM 基线用 `V.pianoTouch`（`v` 封顶 .12），滚得越快越响；
- `chime`：风格台切换时的一声，GYM 基线用 `V.pianoChord`（根音 + 纯四度 + 纯五度）。

首页旋律可以不跟章节 BPM：`RING_SND.melody` 是每格一个音，节奏由滚动速度决定，不必硬套 88–138 BPM。章节环境声才按 BPM 排。

页面转场的风声 `sndSwoosh` 在引擎里，一般不用改。

## 6. 验证

不能只看代码，要实际测峰值。步骤：

1. 进入某一章（`#/ch/N`），**等 2 秒**，让幕布转场的风声过去、环境声淡入稳定。
2. 开声，接一个 AnalyserNode，然后用 `lbFromPic` 点开一张照片。不要用改网址的方式打开，那样可能又触发一次幕布和风声。
3. 量 3 秒的峰值，然后关闭大图。
4. 每章**测 3 次，取中位数**。单次差异主要来自和弦落点与混响尾巴的相位，单次能差 1.5 倍，多测几次。
5. **七章一起比**：每章中位数都要落在 0.10–0.32 内，最响与最轻相差不超过 3 倍。跑动密的章（减脂、肩部、舞蹈）峰值天然高，别因此去压总线；降这一章的 `v`、减少同时落下的音数，或拉开 `pianoRun` 的 `gap`。瑜伽和普拉提留白多，事件音也短，别让它们轻到测不出来。

```js
setSound(true);
const an = SND.ac.createAnalyser(); SND.out.connect(an); let peak = 0; const b = new Float32Array(2048);
const iv = setInterval(()=>{ an.getFloatTimeDomainData(b); for (const v of b) peak = Math.max(peak, Math.abs(v)); }, 20);
lbFromPic(CH.figs[0].el.querySelector(".pic"));
await new Promise(r=>setTimeout(r, 3000)); clearInterval(iv); peak;   // 记下来，再 lbRequestClose()
```

每章的中位数都要落在预算内，改完力度以后要整轮重测。浏览器面板在后台时 `requestAnimationFrame` 可能暂停，大图会卡在聚拢阶段，先截一张图把页面唤醒。

**环境声单独的快检**（不打开大图）：进章等 2 秒淡入，接 AnalyserNode 量 1.8 秒。钢琴环境声的读数通常比带鼓组的册子低（本站实测 0.04–0.08 一档），这是正常的——只要最高与最低不超过 3 倍、没有一章是 0 或削波即可。它能快速发现「加章忘了配 SCENES」或某一章力度写错，但不能替代上面的大图峰值测量。

最终的听感要请用户自己听。测量只能保证不爆、不哑；触键够不够轻快、跑动颗粒清不清楚、留白够不够，要人耳判断。门店大屏默认关声时，也要点一次确认接通正常。
