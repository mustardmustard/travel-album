# 声音：全部现场合成

声音不是背景音乐，它是训练质感的第三个层面（原理 4）。整个站不放任何音频文件，所有声音都用 Web Audio 在浏览器里现场合成（原理 5）。本册的方向是**欧美动感 house / EDM**：力量章 124–128 BPM 四四拍底鼓、反拍 hi-hat、sub bass、和弦 stab、明亮 lead、riser / sweep；减脂冲到 132 BPM、舞蹈走 130 BPM 的 house 反拍；瑜伽 100 BPM、普拉提 92 BPM 转成 chill / downtempo，鼓组几乎撤掉，只留长音、气息和留白。

## 1. 硬规则

- **开启时机**：`THEME.soundOn` 默认开启。若浏览器允许自动播放，加载后直接接通；否则在首次 `pointerdown`、`pointerup`、`touchend` 或 `keydown` 时恢复播放（`sndFirst`）。触摸结束事件用于兼容移动浏览器。滚轮和悬停不算用户操作。顶部的 Sound 按钮可以关掉，关闭后后续手势不会自动重新开启。门店大屏、前台展示这类常年无人交互的部署，把 `THEME.soundOn` 设为 false，由第一次点击开启，不要依赖自动播放。
- **启用与播放分开**：`SND.on` 是用户的开关选择，`sndReady()` 判断音频是否实际运行。只有 `sndReady()` 为真时才排声音，避免在浏览器暂停自动播放时积压音符。均衡器只在实际播放时跳动。
- **总线**（`sndInit`）：
  - `SND.out` 接压缩器（threshold -16、ratio 8），再接扬声器，作用是防爆音，保留不动；
  - `SND.fx` 走悬停音、转场和大图音；
  - `SND.lp` 是章节环境声，前面有一个低通滤波器；
  - `SND.wet` 是卷积混响。house / EDM 的节拍要干净：混响由 4.2s 缩到约 1.2s、wet 降到约 .2、预延迟约 12ms，别让长尾把底鼓糊住。
- **音阶与音量**：GYM 基线 `THEME.scale = [0,2,3,5,7,9,10]` 多利亚、`base = 57`、`presence = .9`。
- **让位**：打开大图时，`sndDuck(true)` 把环境声压到 30%，并让它变闷（低通 750Hz）。
- **切走标签页再回来**时，不补放积压的音（`sndTick`）。
- **零音频文件**：house 的鼓组、sub、bass、stab、lead、riser / sweep 全部用振荡器和噪声缓冲现场合成，不塞 loop 音频或采样包（原理 5）。
- **音量预算**：参照本站实测，打开大图那几秒的峰值在 0.10–0.32 之间，各章之间相差不超过 3 倍。七章按训练质感排（力量 124 → 126 → 128 BPM 由重到轻，瑜伽 100 BPM 最留白；减脂 132 BPM 最急、舞蹈 130 BPM 最跳、普拉提 92 BPM 最慢）；kick 瞬态高，某一章明显偏响时降这一章乐器的力度 `v`，不要动总线压缩器，也不要靠压总线把 EDM 的冲击力压没。
- **数组对齐**：`LB_SND`、`VOICE`、`SCENES` 都按下标取 `CHAPTERS`。本站 7 章就是 7 项，加章必须三处一起加，否则新章 `SCENES[ci]` 为 `undefined`、`VOICE[ci]` 会抛错。
- **环境声总音量**：`THEME.presence`，对应 DNA 的 `sound.presence`。瑜伽和普拉提章只有铺底和气息，允许它们最轻，但仍要落在预算内，别轻到听不出章与章的差别。

## 2. 乐器表（`V.*`）

主乐器都加在 `Object.assign(V, {...})` 里，签名统一 `(f?, t, dest, v, ...)`。注意 `stab` 的第一个参数是频率数组 `freqs`；`kick / clap / hat / riser / sweep / impact` 没有音高参数，直接从 `t` 开始。

| 乐器 | 签名 | 音色 | 适合的训练质感 |
|---|---|---|---|
| `kick` | `(t, dest, v=.16)` | 四四拍底鼓：正弦 130→48Hz 下扫 + 极短噪声点击 | 硬拉、主项、重与爆发 |
| `clap` | `(t, dest, v=.08)` | 拍手：带通噪声三连微爆发 | 2/4 拍、肩部、亮点 |
| `hat` | `(t, dest, v=.035, open=false)` | 高通噪声 hi-hat，closed .045s / open .18s | 反拍律动、16 分切分 |
| `sub` | `(f, t, dest, v=.09, dur=.4)` | 纯低频长音（正弦 + 轻饱和） | 硬拉、根音、最低最重 |
| `bass` | `(f, t, dest, v=.08, dur=.22, o)` | 律动贝斯：锯齿 + 低通包络 | 臀腿、offbeat 切分 |
| `stab` | `(freqs, t, dest, v=.07, dur=.35, o)` | 和弦 stab：多锯齿 + 低通扫 | 臀腿、反拍、和弦铺底 |
| `lead` | `(f, t, dest, v=.06, dur=.3, o)` | 明亮主音：detune 锯齿 + 轻 portamento | 肩部、轻快、悬停与放大镜 |
| `riser` | `(t, dest, v, dur, f0, f1, root)` | 锯齿和弦上扫、共振低通跟随（保留现有实现） | 组间推进、期待感 |
| `sweep` | `(t, dest, v, dur, f0, f1)` | 噪声上扫 | 大图 open、收操气息 |
| `impact` | `(t, dest, v)` | 落地冲击 | 大图 done（成像完成那一声） |

辅助层保留：
- `air(t, dest, v, dur, f0, f1)`：柔和气声，瑜伽章的呼吸与气息；
- `wind(...)`：可调噪声扫频；`vinyl(...)`：底噪；
- `loopNoise(dest, buf, type, freq, q, gain)`：循环噪声，做场馆底噪、通风声、镜面空间感；
- `drone(dest, f, type, gain)`：持续音；
- `lfo(param, rate, depth)`：让一个参数慢慢起伏，瑜伽章的"呼吸感"和滤波器缓慢开合靠它。

**新乐器**：需要表里没有的音色时，比如 tom、牛铃、formant 人声、金属打击，就在 `Object.assign(V, {...})` 里加一个。写法跟现有乐器一样：
- 签名统一是 `(f?, t, dest, v, ...)`；
- 用 `env()` 包络；
- 用 `t` 排程，不用 `setTimeout`；
- 每个源都要 `stop`。

几个常用的合成法：

| 音色 | 做法 |
|---|---|
| 四四拍底鼓 `kick` | 正弦 130→48Hz 指数下扫，起音叠一段极短噪声当点击 |
| 拍手 `clap` | 带通噪声三连微爆发，间隔十几毫秒 |
| hi-hat `hat` | 高通噪声；closed .045s / open .18s |
| sub 低频 | 正弦 + 轻饱和，长包络；别叠高频，免得跟 kick 打架 |
| 律动 `bass` | 锯齿 + 低通包络，落在 offbeat 做切分 |
| 和弦 `stab` | 多个锯齿叠成和弦，低通在 `dur` 内从高扫到低 |
| 明亮 `lead` | detune 锯齿 + 轻 portamento |
| `riser` / `sweep` | 噪声或锯齿上扫，滤波器频率与音量一起上扬 |
| `impact` | 低频正弦 + 噪声瞬态，短促、落地 |
| 长 stab / pad | 多锯齿长音铺底 + 慢 LFO，混响收干（约 1.2s、wet 约 .2） |

## 3. 音阶：按训练强度和项目选

`THEME.scale` 是一个八度里的半音位置，`THEME.base` 是 MIDI 基准音。`hz(音级, 八度, 基准)` 会自动按音阶取音，所以换了音阶，整站的旋律都跟着换。整册只放一条主音阶，靠每章的乐器、音区、节奏和密度区分；`THEME.scale` 是全局的，不要按章改。GYM 基线固定 `[0,2,3,5,7,9,10]` 多利亚、`base = 57`、`presence = .9`。

| 训练强度 / 项目 | scale | 备注 |
|---|---|---|
| 大重量主项、硬拉、铁馆（默认推荐） | `[0,2,3,5,7,9,10]` 多利亚 | 小调底色里有一个大六度，不阴沉也不甜，最贴"重但向前" |
| 爆发、HIIT、冲刺 | `[0,3,5,7,10]` 小调五声 | 音少、落点硬，适合短促 stab 和 kick |
| 臀腿、持续组、稳定推进 | `[0,2,3,5,7,8,10]` 自然小调 | 比多利亚多一个小六度，张力更连续 |
| 肩部、精准轻快、明亮 | `[0,2,4,5,7,9,11]` 大调 | 明亮 lead 在上，仍用 EDM 鼓组托住 |
| 瑜伽、收操、呼吸、留白（100 BPM） | `[0,2,4,7,9]` 大调五声，或仍用上面的多利亚 | 五声没有半音，留白不刺；配 chill / downtempo 铺底 |
| 康复、评估、冷静 | `[0,2,4,7,9]` 大调五声 | 平和，不 pushing |

`base` 的选法：重、暗的项目取 55–60，明亮轻快的取 60–67。GYM 基线取 57。

音阶按**训练强度 / 项目**选，不要拿地域性音阶当正面示例：健身房展示听的是重量和节奏，不是地域色彩。

注意：音阶长度会影响"音级"的含义。五声音阶里音级 5 就是高八度；七声音阶里，高八度是音级 7。`lpListen` 把亮度映射到 0–9 级，在七声音阶里大约覆盖 1.3 个八度，不用改。

## 4. 每章三套声音

三个数组的顺序都对应 `CHAPTERS`，写在「声音：风格区」里，项数必须相等。本站 7 章：硬拉 DEADLIFT → 臀腿 GLUTES → 肩部 SHOULDERS → 瑜伽 YOGA → 减脂 CUTTING → 舞蹈 DANCE → 普拉提 PILATES。新站可以按需增减章数，但每章都要有对应的一项。

### 4.1 环境声 `SCENES[i] = b => ({ nodes, tick })`

环境声 = **底层** + **事件层**。

- **底层**：放进 `nodes` 的持续声源，切章时会自动停掉。来源是 `loopNoise`、`drone` 和 `lfo`。
- **事件层**：`tick(t)` 在时间 `t` 排一个或几个音，然后返回下一次的时间。用 `rnd()` 和 `pick()` 给它一点不规则；house 的鼓组按 BPM 定拍，别用随机数打乱 kick。

GYM 基线 7 章的拆解，可以照这个思路举一反三：

| 章（项目） | 底层 | 事件层 | 节奏 |
|---|---|---|---|
| 硬拉 DEADLIFT | 低通噪声（场馆低鸣）+ sub drone | kick 每拍、offbeat open hat、sub 根音每小节、stab 每 2 小节 | 124 BPM，最重最低 |
| 臀腿 GLUTES | 很轻的通风噪声 | kick 四拍 + 16 分 hat、offbeat bass 切分、反拍 stab | 126 BPM，律动最密 |
| 肩部 SHOULDERS | 带通噪声 | kick + clap 落在 2/4 拍、16 分 hat、lead 短句 | 128 BPM，最轻快最亮 |
| 瑜伽 YOGA | 慢 LFO 的长 stab / pad + air 气息 | soft kick 每 2 拍、大量留白 | 100 BPM（chill / downtempo） |
| 减脂 CUTTING | 明亮带通噪声 + 快 LFO | 每拍双 kick、16 分 hat、反拍 clap、每 4 小节一次 riser | 132 BPM（HIIT），最急最快 |
| 舞蹈 DANCE | 中频通风噪声 | kick 四拍、反拍 open hat、2/4 拍 clap、切分 bass、宽 stab | 130 BPM（house），最跳 |
| 普拉提 PILATES | 低通噪声 + 极慢 LFO | soft kick 每小节一次、长 stab / pad、air 气息、隔小节一次 lead 琶音 | 92 BPM（downtempo），最慢最柔 |

配方原则：
- **按训练质感排，不必是一条单调的递减曲线**：前四章走「一次训练」由重到轻，后三章是另外三种项目性格（冲刺 / 律动 / 控制）。
- 别把瑜伽和普拉提做成鼓组齐鸣；这两章靠长音、气息和留白区分，一个偏"呼吸"、一个偏"控制"。
- **底层决定"在哪练"，事件层决定"这一章什么质感"**。比如：
  - 铁馆力量区 = 低通场馆底噪 + kick 每拍与 sub 根音；
  - 团课区 = 四四拍 kick + 16 分 hat + offbeat bass 切分；
  - 瑜伽 / 收操 = 长 stab / pad + air 气息 + 大量留白，soft kick 只每 2 拍。
- 每章至少在底层、乐器、节奏三者中的两项上跟相邻章不同。
- 全部现场合成：kick、hat、clap 是振荡器与噪声缓冲拼出来的，不要塞 loop 音频文件（原理 5）。

### 4.2 悬停音色 `VOICE[i] = (f, t, dest) => …`

首页悬停某章的照片时，用这一章的乐器弹一个音。GYM 基线里 `VOICE` 统一用 `lead` / `stab` 的短音（小 `v`、短尾），别拿全力度 `kick` 或 `impact` 当悬停音。

悬停音触发得最频繁，最容易刺耳，所以有几条额外规矩：
- **音高由照片决定**：`sndHover` 用 `photoLum` 读照片的平均亮度，暗照片低、亮照片高（音级 0–7）。不要用"第几章、第几张"去算音高。
- **不往上翻到 1–4kHz**：那是人耳最敏感的频段。要升八度时用 `hz` 把八度参数加 1，超过 900Hz 就不升。
- **用柔和版乐器**：`V.lead` / `V.stab` 给悬停用时都要降力度、缩短尾音；`V.*` 里提供 `soft` 开关的就打开，没有就把 `v` 乘 0.3–0.5。
- **音量按实测响度拉平**：`lead` 的 detune 锯齿和 `stab` 的多锯齿峰值天然比 `hat` 高，按 RMS 拉平后别让某一章的悬停音比别的章响一截。
- 悬停音走 `SND.hov` 总线，上面有一道 3.2kHz 的柔和低通；两次触发至少间隔 90ms。

### 4.3 大图事件音 `LB_SND[i] = { open, step, done, look, swap, close }`

GYM 基线里 `LB_SND` 用 `sweep(open)`、`hat(step)`、`impact(done)`、`lead(look/swap)`、下行琶音 `(close)`。

| 事件 | 时机 | 写法 |
|---|---|---|
| `open(t)` | 粒子开始聚拢 | 一个"聚气"的声音：`sweep` 上扫、`riser`、`sub` 起声；硬拉章用短 riser 加 sub，瑜伽章只用一段慢 sweep |
| `step(t, j)` | 显影每升一级，j = 0–6 | 用 `hat` 点 7 下，音级随 j 上行、力度很小；7 级连起来是一条上行音阶 |
| `done(t)` | 成像完成 | 一声 `impact` 落地，是整套里最"满"的一声；瑜伽章给一个轻和弦代替 |
| `look(t, d, v)` | 放大镜划过；d = 亮度对应的音级（0–9），v = 饱和度对应的力度 | 用 `lead` 的短点音，`v` 乘一个很小的系数，因为会频繁触发 |
| `swap(t)` | 左右切换照片 | `lead` 的短促过渡音 |
| `close(t)` | 关闭，粒子飞回 | 一段下行琶音，跟 `open` 呼应 |

`arp(t, 音级数组, 间隔, (音级, 时间) => …)` 用来写琶音。

七章的事件音各有性格：硬拉章最重（impact + sub）、减脂最急（clap + impact）、舞蹈靠拍手和弦、瑜伽与普拉提最稀最长，别让相邻两章听感一样（原理 4）。

## 5. 首页的声音：`RING_SND`

在「声音：风格区」的最前面：
- `melody`：照片环每滚过一格，弹旋律里的下一个音级，自动高一个八度；
- `step`：弹旋律的乐器，GYM 基线用 `V.lead`，可以按 DNA 换成这一册的主乐器；别用全力度 kick，首页每滚一格都响会吵；
- `chime`：风格台切换时的一声，GYM 基线用 `V.stab`。

首页旋律可以不跟章节 BPM：`RING_SND.melody` 是每格一个音，节奏由滚动速度决定，不必硬套 124–128 BPM。章节环境声才按 BPM 排。

页面转场的风声 `sndSwoosh` 在引擎里，一般不用改。

## 6. 验证

不能只看代码，要实际测峰值。步骤：

1. 进入某一章（`#/ch/N`），**等 2 秒**，让幕布转场的风声过去、环境声淡入稳定。
2. 开声，接一个 AnalyserNode，然后用 `lbFromPic` 点开一张照片。不要用改网址的方式打开，那样可能又触发一次幕布和风声。
3. 量 3 秒的峰值，然后关闭大图。
4. 每章**测 3 次，取中位数**。house 鼓组是定拍的，单次差异主要来自 riser / sweep 的随机事件，单次能差 1.5 倍。混响收干后读数会比长混响时更稳，但仍要多测几次。
5. **七章一起比**：前四章峰值应随强度递减（硬拉 ≥ 臀腿 ≥ 肩部 ≥ 瑜伽），减脂 / 舞蹈因为拍手和双 kick 会回到较高一档，普拉提最轻；但每章中位数都要落在 0.10–0.32 内，最响与最轻相差不超过 3 倍。硬拉、减脂章有 kick，峰值天然高，别因此去压总线；降这一章乐器的 `v` 或 `presence`。瑜伽和普拉提只有铺底和气息，别让它们轻到测不出来。

```js
setSound(true);
const an = SND.ac.createAnalyser(); SND.out.connect(an); let peak = 0; const b = new Float32Array(2048);
const iv = setInterval(()=>{ an.getFloatTimeDomainData(b); for (const v of b) peak = Math.max(peak, Math.abs(v)); }, 20);
lbFromPic(CH.figs[0].el.querySelector(".pic"));
await new Promise(r=>setTimeout(r, 3000)); clearInterval(iv); peak;   // 记下来，再 lbRequestClose()
```

每章的中位数都要落在预算内，改完力度以后要整轮重测。浏览器面板在后台时 `requestAnimationFrame` 可能暂停，大图会卡在聚拢阶段，先截一张图把页面唤醒。

**环境声单独的快检**（不打开大图）：进章等 2 秒淡入，接 AnalyserNode 量 1.8 秒。本站 7 章实测 0.134 / 0.125 / 0.121 / 0.079 / 0.110 / 0.123 / 0.080；瑜伽和普拉提几乎不放鼓，低于 0.10 是正常的（0.10–0.32 是「打开大图那几秒」的预算，含事件音），只要最高与最低不超过 3 倍、没有一章是 0 或削波即可。它能快速发现「加章忘了配 SCENES」或某一章力度写错，但不能替代上面的大图峰值测量。
